# 04 RELEASE — リリース戦略とリスク

## 段階

### 1. 小規模運営（SNS）
- 友人と遊べる対戦モード（人間と AI の混在可）
- 多機能なルール設定を売りにする
- 友人と遊ぶ様子を配信する
- Web 版として公開（サーバー権威型の対戦サーバー）

### 2. 反響があれば本格リリース
- 求められているニーズを反映する
- **Steam**：Web 版を Electron などで包む。Steam 連携は steamworks.js などを使う
- **スマホアプリ**：Capacitor などで包む。Rust エンジンは同じ WASM をそのまま使う

## 差別化の軸

- 多機能なルール設定（AI もそのルールで打つ）
- AI の推論を活かしたアシスト（相手の待ち確率の可視化など、公開情報のみで推論）
- 長期的には「打牌理由を自然言語で説明する AI」

## リスクと対策

| リスク | 対策 |
|---|---|
| 学習データの権利 | 天鳳の牌譜は使わない。自己対戦で生成したデータのみ使う |
| 参考実装のライセンス | majiang-core は MIT。本体リポジトリのコード・画像は流用前に個別確認 |
| 素材の権利 | 牌面画像・音声・フォントは自作か商用利用可能なものに限る |
| 不正（手牌の盗み見） | サーバー権威型。牌山と他家の手牌をクライアントへ送らない |
| ストア審査（賭博に見える） | 実際の金銭価値との交換がない設計。年齢区分・課金規約を各ストアごとに確認 |
| サーバー費用 | CPU 対戦・牌譜再生は端末内で完結させ、サーバーは対人戦のみに使う |
