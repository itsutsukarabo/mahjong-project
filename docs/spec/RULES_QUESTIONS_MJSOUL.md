### I-3 の詳細仕様（オーナーの記述をそのまま残す）
1. 積み棒（本場）の扱い（天鳳・雀魂共通）
   天鳳・雀魂ともに「包（パオ）が発生した場合、ツモ・ロンにかかわらず、積み棒は包となった者が全額支払う」というルールを採用しています。
   複合役満となって他のプレイヤーが点数の支払いに巻き込まれるケース（後述の雀魂など）であっても、積み棒を頭割りで払ったり放銃者が払ったりすることはなく、100%包のプレイヤーが負担します。
2. 複合役満時の「点数本体」の扱い（天鳳と雀魂での差異）
   「大三元（包）＋字一色」などの複合役満（ダブル役満）が発生した場合、点数自体の責任払いの適用範囲が天鳳と雀魂で異なります。実装時にはどちらのルールに準拠するか（あるいは切り替え可能にするか）注意が必要です。
   - 天鳳の仕様（全額責任払い）複合した他の役満（字一色など）の点数も含めた全額（ダブル役満なら全額）が責任払いの対象になります。
     - ツモ和了: 包の人が、複合役満の全点数＋積み棒を1人で払います。
     - ロン和了: 包の人と放銃者で、複合役満の全点数を半分ずつ（折半）払います。積み棒は包の人が全額払います。
   - 雀魂の仕様（パオ部分のみ責任払い）パオ対象の役満（大三元など）のみが責任払いの対象となり、複合した他の役満（字一色など）は通常通り精算されます。
     - ツモ和了: 大三元分は包の人が全額払い、字一色分は通常のツモ和了として同席者で割ります（包の人も字一色分の支払いに参加します）。積み棒は包の人が払います。
     - ロン和了: 大三元分は包の人と放銃者で折半し、字一色分は放銃者が全額払います。積み棒は包の人が払います。

ツモ損との組み合わせ（オーナー確認 2026-11-28 回答 E）：包の人が払うのはツモ損後の合計額（子の役満ツモなら 24000点、親の役満ツモなら 32000点）。テストは `mj-core::pao_tsumo_with_tsumo_payment`・`pao_scope_full_and_pao_yaku_only`・`pao_honba_pao_and_normal`。
