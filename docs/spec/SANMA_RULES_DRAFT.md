## 決め方の提案（判断材料）
1. **A1 を先に決める**と他の多くが決まる。(a)(b) なら RiichiEnv のプリセットと突き合わせられるので、Phase 0〜1 のエンジン検証が楽になる（ENGINE_SURVEY §6）。(c) なら仕様テストを全部自前で書く
2. RL の観点で影響が大きいのは **B5（ツモ損）・C3（赤枚数）・D1〜D3（北）・B4（1局戦の原点）**。カリキュラム①②の設計（打点の圧縮強さ・報酬の正規化）に直結する
3. ゲームとしての売り（多機能なルール設定）のため、ここに挙げた選択肢は**メインで採らないものも設定値として実装する**前提。メインの選択はモデルの専門化先を決めるもので、実装範囲は狭めない
